# Can LLMs simulate electric machines?

Slides from the Swedish Electromobility Centre digital-twin workshop,
1 October 2026.

**[View the deck →](https://pfyhr.github.io/can-llm-sim-em/)**

Two years of putting an LLM agent to work on electromagnetic FEA of electrical
machines, using an open toolchain — gmsh, Elmer FEM, Python — with an external
validation gate at every step. A ladder of five rungs, from an air-cored
solenoid checked against the exact on-axis integral to a bought-and-measured
production motor.

The conclusion is deliberately unglamorous: LLMs do not predict physics, they
operate simulators — competently, and fast enough to change what is worth
simulating. The engineer's irreducible contribution is the validation gate.

This repository holds the built deck only. The models, meshes and analysis code
behind it are not public.
